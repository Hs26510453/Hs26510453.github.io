# Imaya Devindi — E-Portfolio

Personal e-portfolio for **SC1172: Introduction to Information Technology**.

## Contents
- `index.html` — portfolio homepage
- `style.css` — responsive styling
- `profile.png` — profile photograph
- `Imaya_Devindi_CV.pdf` — downloadable résumé (from Assessment 01)

## Publish using GitHub Pages
1. Sign in to GitHub and find your exact GitHub username.
2. Create a **public** repository named `YOUR_USERNAME.github.io` (replace YOUR_USERNAME).
3. Upload all four website files to the **root** of the repository and commit.
4. Go to **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.
5. Visit `https://YOUR_USERNAME.github.io/` once GitHub finishes publishing.
6. Test every navigation link, the email button, and the résumé download.

**Privacy note:** The résumé contains personal contact details. Publishing it makes these details publicly accessible. Review and remove any information you do not want public before uploading.
